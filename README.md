# Zenith Stats

Aplicación web para registrar partidas de Riftbound y consultar estadísticas personales por leyenda y tipo de mazo. La base del proyecto usa Next.js y TypeScript.

## Arranque en local

Usa Node.js 24 y npm.

```powershell
npm.cmd ci
npm.cmd run dev
```

Abre [la página local](http://localhost:3000). En macOS o Linux, usa `npm` en los mismos comandos.

Para verificar la compilación, ejecuta `npm run build` (`npm.cmd run build` en PowerShell).
